英语期末复习

Unit 1 · 翻译

英译汉和汉译英都可以放在这里。每个翻译组可以保存一篇长文章，每个段落独立保存英译汉内容，可自由添加、删除、收缩和展开。手机和平板可通过 GitHub 同步同一份题库。

Unit 1 · 选择题

一个 Unit 可以有多个大组，例如“一、单项选择题”“二、课后练习”。每个大组里的一道题都是独立的小题卡片，可以单独收缩或删除。

当前单元还没有大组，点击“＋添加大组”即可。

GitHub 同步设置

只用于你自己的复习工具。Token 只保存在当前设备浏览器中，不会写入题库文件。请使用 GitHub Fine-grained Personal Access Token，并只给这个仓库的 Contents 读写权限。

手动批量录入选择题

先选择一个大组，再把已经整理好的题目粘贴进来。程序会自动识别题号、A/B/C/D 四个选项和“答案”。一个大组里，每一道题都会单独显示成一个小题卡片。
